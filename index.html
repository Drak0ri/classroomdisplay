⚙️ Setup Guide

Step 1: Create a new Google Sheet in your barryjshaw account.
Step 2: Copy the Sheet ID from the URL and paste it into apps-script.gs.
Step 3: Create a new Apps Script project (script.google.com), paste apps-script.gs, deploy as Web App.
  — Execute as: Me | Access: Anyone
Step 4: Copy the deployment URL and paste it into the field above.
Step 5: Click Save URL, then load rooms.

Kiosk Mode: In Google Admin Console → Device Management → Kiosk Apps → add the wall screen URL for each device.
